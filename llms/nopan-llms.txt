# Nopan

> Nopan is a specialized Payment Service Provider (PSP), built by former merchants and Netflix payments leaders, focused exclusively on European account and wallet payment methods (Wero, BLIK, Bizum, Satispay, IRIS). It exposes a single standardized API for A2A and wallet payments with optimized conversion flows, PSP-agnostic tokenization for recurring/MIT payments, a multi-currency settlement engine, and normalized transaction data. Licensed as a Payment Institution by De Nederlandsche Bank (DNB); PSD2/SCA compliant.

## APIs
- [Nopan API](https://api.nopan.io): OAuth2 client_credentials over mTLS with JWS request signing. Base URL https://api.nopan.io.

## Specs
- [OpenAPI (original)](https://docs.nopan.com/redocusaurus/plugin-redoc-0.yaml): OpenAPI 3.0.3, 16 operations across Authentication, Payment Processing, Testing, Webhooks, and Reporting.

## Operations
- getAccessToken — POST /auth/token
- initiatePayment — POST /payments/initiate
- finalizePayment — POST /payments/finalize
- chargePayment — POST /payments/charge
- capturePayment — POST /payments/capture
- cancelPayment — POST /payments/cancel
- refundPayment — POST /payments/refund
- getPaymentStatus — GET /payments/{transactionId}/status
- getPaymentEvents — GET /payments/{transactionId}/events
- mockPayment — POST /mock/set
- searchReports — GET /reports
- downloadReport — GET /reports/download
